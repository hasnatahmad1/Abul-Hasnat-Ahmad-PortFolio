# Abul Hasnat Ahmad — Portfolio

Personal portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
```

## Edit content

All text (profile, experience, projects, skills, education) lives in `src/data.js`.
To update the CV, replace `public/Abul_Hasnat_Ahmad_CV.pdf`.

## Build

```bash
npm run build    # outputs static files to dist/
```

The `dist/` folder can be hosted on any static host (GitHub Pages, Netlify, Vercel).
